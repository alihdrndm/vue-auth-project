How accurately does Eingang read invoices?

Every number on this page is a sample. Real results replace them after the first published test run.

Method

  1. 1Corpus. Public sample invoices, each a PDF with the XML inside (ZUGFeRD and Factur-X).
  2. 2Ground truth. The AI reads only the PDF; every value is compared with the XML inside the same file.
  3. 3Baseline. A regex reader runs on the same files, so the AI has something to beat.
