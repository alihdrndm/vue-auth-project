# M7 — Frontend part 1: tokens, components, inbox and review

## What was built

- **Design tokens and base styles** from the design export, with the design's names; fonts are self-hosted; a lint step rejects raw hex colours outside `tokens.css`.
- **Base components** with tests: button (with a visible reason when disabled), inputs, status/severity/format chips, confidence bars, a sortable table, WAI-ARIA tabs, a dialog on `<dialog>`, toasts, skeleton, empty and error states, the stamp, and the **app shell** (rail, phone tab bar, `/` search, sandbox banner on every app page).
- **API layer:** a typed `openapi-fetch` client with CSRF and problem+json errors, TanStack Query defaults (no retry on 4xx, no polling in a hidden tab), a session store and route guard.
- **Screens:** sign-in; the inbox (tabs with counts, filters and sorting in the URL, live processing steps, uploads one file per request, three at a time, each with its own progress and error); the invoice review (PDF.js, the sandboxed XML visualisation, XML and text tabs, validation, checks with the resolve flow, fields with confidence and evidence, lines, VAT, timeline, actions from `allowed_actions`).

## Key decisions

1. **The server decides, the UI shows.** Action and resolve buttons come from the API, enabled or disabled with a visible reason; the UI never computes permissions.
2. **Every AI value carries its evidence.** LLM-read fields show High/Medium/Low and, on hover or focus of the eye, the exact snippet with the value marked; XML values say "From the XML"; an edit becomes "Edited by …".
3. **State in the URL.** The inbox's tab, search, filters, ordering and page live in the query string, so back/forward work and the review's `j`/`k` walk the same list (`?from=`).

## Keyboard-only walkthrough (upload → review)

Run in Chromium with Playwright against the seeded dev stack:

1. Sign in: type email and password, Enter submits.
2. Inbox: `/` focuses the search, Escape leaves it. Tab reaches **Upload invoices**; Enter opens the dialog, Escape closes it and focus returns to the button. (Choosing files opens the system file picker, which Playwright doesn't drive.)
3. Tab passes nav, tabs, filters and sortable headers to the rows; Enter on a row opens its review.
4. Review: `j` goes to the next invoice. Tab reaches a field's **Edit**; Enter edits, typing and Enter save ("… saved."), Escape cancels. Tab reaches **Resolve…**; Enter opens the dialog with focus in the note; Escape closes it and focus returns to **Resolve…**.
